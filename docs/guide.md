# Руководство

## Работа в команде

- Свои тикеты ищите в Issues по фильтру `assignee:@me`. Открывайте тикет в своём агенте (`/implement #номер`) и работайте в отдельной ветке и рабочем каталоге или worktree.
- Начинайте тикет, когда закрыты его блокеры: они видны в самом issue. Контракт среза записан в родительском issue среза.
- В PR пишите `Closes #номер`. Когда закрыт последний тикет среза, срез и спека закрываются сами.
- Чтобы передать тикет, снимите себя с него, и workflow назначит другого участника. Чтобы выбрать преемника самому, сначала добавьте его, потом снимите себя. Ветка и незаконченный PR при передаче не переносятся, договоритесь о них с новым владельцем.
- Уходите из команды — удалите себя из `.agents/team.json`, иначе тикет может вернуться к вам. Тикет, который не нужно распределять, держите без метки `ready-for-agent`.
- Кому что досталось и почему, видно в логе workflow **Distribute tickets**. Посмотреть план, ничего не меняя: `python .agents/workflow/distribute.py --team .agents/team.json`.

Точные правила распределения: [distribution.md](../.agents/workflow/distribution.md).

## Перенос в существующий репозиторий

1. Скопируйте `.agents/`, `.claude/`, `.github/workflows/distribute.yml`, `.github/workflows/close-parents.yml`, `AGENTS.md`, `CLAUDE.md`, `GLOSSARY.md` и `docs/`, при желании `tests/`. Если такие файлы уже есть, объедините их, сохранив свои инструкции.
2. Выполните шаги 2–5 из README.

Старые issues без метаданных распределения workflow не трогает. Если workflow падает из-за прав, проверьте **Settings → Actions → General → Workflow permissions**.

## Обновление скиллов и проверка

Скиллы взяты из [mattpocock/skills](https://github.com/mattpocock/skills), commit `a496f5513d4a4cf889bc48e189e579f4b0bdf6aa`. Мы изменили два из них, и при обновлении эти изменения нужно сохранить:

- `.agents/skills/to-tickets/SKILL.md`: нарезка срезов на тикеты по ролям и распределение;
- `.agents/skills/triage/SKILL.md`: метаданные распределения при переводе в `ready-for-agent`.

Если добавляете или переименовываете скилл, создайте для него обёртку в `.claude/skills`.

Тесты запускаются из корня репозитория: `python -m unittest discover -s tests -v`.
