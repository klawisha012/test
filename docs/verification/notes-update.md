# Проверка изменения заметки через API

Тикет проверки: #18. Контракт среза: #16. Проверено 2026-11-03
после слияния PR #19 и закрытия блокирующего тикета #17.

Проверен коммит `b5e1c6a` через настоящий HTTP: приложение `server.notes.app`
запущено на `wsgiref.simple_server` с адресом `127.0.0.1` и свободным портом.
Запросы отправлены через `urllib.request`, без моков и прямого изменения хранилища.
После проверки сервер остановлен.

| Действие | Результат |
| --- | --- |
| `POST /notes`, `{"text":"купить хлеб"}` | 201, заметка с числовым id |
| `PUT /notes/{id}`, `{"text":"купить молоко"}` | 200, тот же id и новый текст |
| `GET /notes` | 200, список содержит изменённую заметку |
| `PUT /notes/{id}`, `{"text":""}` | 400; последующий GET сохраняет новый текст |
| PUT с текстом из пробелов, табуляции и перевода строки | 400; последующий GET сохраняет новый текст |
| `PUT /notes/999` с непустым текстом | 404 |

Все проверки ответов выполнены утверждениями Python и прошли.
Критерии приёмки среза #16 выполнены: изменённый текст возвращается в списке,
пустой текст отклоняется.

Автоматические проверки реализации перед слиянием PR #19:

- `python -m unittest discover -s tests`: 26 тестов прошли.
- `node --test tests/notes-api.test.mjs`: 4 теста прошли.
- `git diff --check`: без ошибок.

Срез описывает изменение через API. Форма изменения в браузере в его контракт
не входит. Хранилище остаётся в памяти и очищается при остановке процесса.
