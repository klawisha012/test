# Командный процесс

Как команда людей делит работу из GitHub Issues между собой. Агенты помогают участникам, но сами не являются участниками.

## Language

**Участник**:
Человек из состава команды, которому можно поручить тикет.
_Avoid_: исполнитель, агент, member

**Роль**:
Специализация участника из справочника ролей, например frontend или backend. У участника может быть несколько ролей.
_Avoid_: навык, skill, должность. Метки состояния в `/triage` тоже называются roles, но это другое понятие.

**Справочник ролей**:
Закрытый список ролей команды с описанием каждой. Роли вне справочника не существуют.
_Avoid_: теги, список навыков

**Владелец**:
Единственный участник, который отвечает за тикет и может работать над ним с любым агентом.
_Avoid_: исполнитель, assignee

**Срез**:
Поведение, которое видит пользователь и которое можно показать целиком, например «можно зарегистрироваться». Срез — это единица планирования. Он состоит из одного или нескольких тикетов.
_Avoid_: tracer bullet, вертикальный слайс, фича, user story

**Тикет**:
Единица работы с одним владельцем. Тикет требует одну роль или ни одной. Тикет без роли может взять любой участник. Обычно тикет — это часть среза для одной роли.
_Avoid_: задача, issue

**Тикет проверки**:
Тикет без роли, в котором части среза соединяют и проверяют поведение среза целиком. Его можно начать только после того, как закрыты все остальные тикеты среза.
_Avoid_: интеграционный тикет, integrate-and-verify

**Контракт**:
Договорённость о том, как стыкуются тикеты одного среза: API, формат данных. Благодаря контракту тикеты разных ролей можно делать параллельно.
_Avoid_: интерфейс, API-спека

**Оценка**:
Относительный объём работы по тикету.
_Avoid_: estimate, сторипойнты

**Ёмкость**:
Относительная доля работы, которую готов взять участник.
_Avoid_: capacity, вес

**Распределение**:
Назначение владельца тикету, у которого владельца нет, с учётом роли тикета и нагрузки участников. Тикет с владельцем распределение не меняет.
_Avoid_: раздача, балансировка

**Передача**:
Смена владельца тикета. Участник делает её вручную: снимает прежнего владельца, и тикет снова проходит распределение.
_Avoid_: handoff, автоматическая передача
